# القرآن الكريم — الإصدار 0.1

بنية أولية احترافية لتطبيق قرآن يعمل على Android وiOS باستخدام Flutter.

## الوضع الحالي

- بنية مشروع قابلة للتوسع.
- دعم العربية وRTL.
- ثيم فاتح/داكن.
- شاشة رئيسية أولية.
- شاشة مصحف أولية مع تقليب الصفحات.
- نموذج الضغط المطول لخيارات الآية.
- لا يحتوي المشروع عمدًا على نص قرآني تجريبي؛ سيتم إدخال مصدر معتمد بعد التحقق من المصدر والترخيص.

## تشغيل المشروع

1. ثبّت Flutter وAndroid Studio وXcode (لـ iOS على macOS).
2. من مجلد المشروع نفّذ:
   - `flutter pub get`
   - `flutter analyze`
   - `flutter test`
   - `flutter run`

## الخطوة التالية

إضافة طبقة بيانات القرآن المعتمدة، ثم بناء نظام تحقق آلي للنص والصفحات قبل ربطه بواجهة المصحف النهائية.
