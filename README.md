# القرآن الكريم — 0.2

بنية Flutter منظمة وجاهزة للتوسع نحو تطبيق قرآن احترافي Android/iOS.

مهم: لا يحتوي هذا الإصدار على نص قرآني تجريبي. سيتم إدخال مصدر موثوق ومرخّص
بعد التحقق من المصدر، ثم إضافة اختبارات آلية للنص والسور والآيات والصفحات.

## تشغيل
flutter pub get
flutter analyze
flutter test
flutter run
